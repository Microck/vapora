# vapora 2.2.5

Graph images now export with a 4,096-pixel long edge, independent of the window size. Geometry and labels render at export resolution, using loaded original profile pictures. Camera position, filters and selection stay unchanged.

- Network arranges automatically. Pause and Resume control the layout; hover no longer resizes or reorders circles.
- Help uses headings and short points beside its control, without covering the control itself. Scrollbars keep the square classic Steam bevels.
- Friends search sits directly above the table. The Obsidian vault download is also available in the main Results actions.
- Attached history stays in a Results tab. The standalone viewer remains available from the rail, with account states kept separate. Failed refreshes retain the saved capture and retry guidance when reopened.
- History uses a compact account/date toolbar and grouped actions. Coverage notices show counts, with details in contextual help.

Image resolution does not add detail absent from an original avatar. Dense graphs can still take time to arrange and render.

Windows downloads include an installer and a portable EXE. The portable app keeps data in `Vapora-data` beside the EXE and needs about 1 GB free in Windows TEMP, plus space for scan data. Move the EXE and data folder together. Downloads are unsigned and not notarized; verify them against `SHA256SUMS.txt`.

Native package tests use local provider fixtures. This release does not change live Steam or history fetching behavior.
