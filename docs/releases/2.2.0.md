# vapora 2.2.0

SteamHistory loads automatically when you verify or select a Steam account. History collection runs separately from Steam scans, and saved captures stay available when a refresh fails.

- Browse friendship periods, comments, persona and real names, URLs, avatars and historical profile/ban details. Search, filter by date and inspect the original fields.
- Use the restored count-based friend and comment rankings, configurable reference populations, optional bounded overlap signals and exact sum/product location calculations. Captured evidence does not prove a relationship or residence.
- Keep every distinct original capture and comment version. Imports, ranking saves, refreshes and reopened runs retain attached and cached evidence; identical imports do not duplicate sources. Newer dated evidence wins without hiding contradictory records.
- SteamHistory's summary and accessible record counts stay separate. For the checked profile, the summary listed eight comments while public endpoints returned five. Vapora preserves all five and marks coverage partial. Deleted comments require SteamHistory supporter access; the exact discrepancy may also come from an outdated summary. A Steam API key does not grant supporter access.
- Historical record dates that are null or malformed remain **Undated** and stay outside date filters. VAC counts survive Steam collection, saved reports and exports.

Windows x64 installer and portable EXEs, Linux x64 AppImage and macOS Apple Silicon DMG include the history helper and browser. No separate Node.js, Python or browser installation is needed for desktop downloads. The bundled runtime increases download size, and provider verification or access restrictions can still prevent loading.

Portable data stays in `Vapora-data` beside the EXE. Move both together. Remembered keys remain tied to the OS account and machine that encrypted them.

Saved files that do not match the current schema are rejected without automatic conversion or overwriting. Start a fresh scan and save current settings; original SteamHistory captures can be imported explicitly.

Downloads are unsigned and not notarized. Verify your download against `SHA256SUMS.txt`. Native package checks use local HTTP fixtures; the small live Steam and SteamHistory checks do not establish coverage for large live networks.
