# vapora 2.1.0

The classic Steam workspace now has a compact API-key dialog, in-app help and clearer estimates. Clicking a recent avatar selects that account for a new scan; saved reports still open through Results.

- Set **Nodes** to `0` for no node cap, or **Requests/min** to `0` for no application pacing. Depth stays at 1-5. Steam limits, retries and cancellation still apply.
- Opt into **Remember API key** in the desktop app when secure OS storage is available. **Forget saved key** removes the saved copy while keeping the current session usable. Browser keys stay session-only. Linux's insecure `basic_text` storage disables remembering.
- **Exports → Rebuild exports** regenerates a completed run's analysis and CSVs from saved data, without a Steam key or new collection. Ranking, collected observations and attached history stay intact.
- Results distinguish private, unavailable, skipped and unfinished observations. Disabled group/game signals show **Off**. Rebuild older exports to update their coverage counts.
- Network builds when opened and preserves its search, selection and zoom between tabs. Help works on hover, keyboard focus and click/tap, with Escape dismissal.
- Desktop maximize/restore uses the actual window state and aligned frame icons.

Windows x64 installer and portable EXEs, Linux x64 AppImage and macOS Apple Silicon DMG are included. The portable app keeps its data in `Vapora-data` beside the EXE. Remembered keys are tied to the OS account and machine that encrypted them, so enter the key again after moving to another machine.

Downloads are unsigned and not notarized. Check `SHA256SUMS.txt` against your download. These checks use local HTTP fixtures; large live Steam networks remain untested.
