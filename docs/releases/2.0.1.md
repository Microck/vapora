# vapora 2.0.1

Desktop downloads now bundle Electron and Vapora. Download the file for your operating system and architecture; you do not need to install Node.js.

- Windows: run the `.exe` installer.
- Linux: make the `.AppImage` executable and open it. If FUSE is unavailable, use `--appimage-extract-and-run`.
- macOS: open the `.dmg` and drag Vapora into Applications.

The desktop app uses the same classic Steam UI, scanner and reports as the browser app. Enter a Steam Web API key using the toolbar key button. Saved runs stay in the OS app-data directory under `Vapora`.

Downloads are unsigned by a publisher certificate and are not notarized. Windows may show a SmartScreen warning. macOS may require approval in Privacy & Security. Check the source and release verification before approving a download.

## verification

The desktop packaging workflow builds on Windows, Linux and macOS and tests the actual installed or extracted app with fresh storage and a local Steam fixture before saving downloads. It checks bundled assets, native startup, scanning, exports and shutdown. The release runbook requires all native jobs to pass before attaching downloads.

The existing source/browser/CLI workflow remains available. Large live networks remain untested, and ranking/location scores are heuristics rather than proof of real-life relationships or residence.
