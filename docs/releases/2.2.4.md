# vapora 2.2.4

Network now starts with a compact preview. Maximize it inside Vapora to search profiles, filter communities and friend-list coverage, inspect neighbours, drag and pin nodes, and export an image. Profile pictures appear inside the circles, with the original placeholder for missing pictures. The classic Steam olive styling stays throughout.

- Layout runs in a worker. Hover and selection avoid rebuilding the graph; pictures load for readable nodes in view, with limited concurrent requests.
- Cancelling a scan keeps the desktop responsive while the partial report is analysed. Saved checkpoints can still resume.
- Checkpoint polling no longer competes with saving on Windows. Newer account-history choices stay selected when an older saved-run response arrives.
- Active scans show an approximate ETA once enough progress is available.
- Help appears beside its information icon. History notices use neutral wording.

Dense graphs can still take time to arrange and render, especially with a software GPU. ETA is an estimate, not a completion guarantee.

Windows downloads include an installer and a portable EXE. The portable app keeps data in `Vapora-data` beside the EXE and needs about 1 GB free in Windows TEMP, plus space for scan data. Move the EXE and data folder together. Downloads are unsigned and not notarized; verify them against `SHA256SUMS.txt`.

Native package tests use local provider fixtures. This release does not change live Steam or history fetching behavior.
