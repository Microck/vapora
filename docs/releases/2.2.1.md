# vapora 2.2.1

Fixes the Windows portable EXE silently failing to open when the system drive has little free space.

- Extracts temporary app files beside the portable EXE and removes them when the app closes. The bundled history helper and browser use that drive too.
- Shows extraction progress and an error if the EXE's drive lacks space or its folder is not writable.
- Preserves saved runs, settings and encrypted keys in `Vapora-data`. Move that folder together with the EXE.

Windows x64 installer and portable EXEs, Linux x64 AppImage and macOS Apple Silicon DMG include their runtime. Desktop downloads need no separate Node.js, Python or browser installation.

Downloads are unsigned and not notarized. Verify your download against `SHA256SUMS.txt`.
