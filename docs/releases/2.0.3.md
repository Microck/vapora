# vapora 2.0.3

Windows now has a portable download alongside the installer. Open `vapora-2.0.3-win-x64-portable.exe` without installing Vapora or Node.js.

Keep the portable EXE in a writable folder. Runs, exports, settings and session files stay in `Vapora-data` beside it. Move the EXE and that folder together to keep your saved runs. `VAPORA_ROOT` overrides the data location if you set it. Existing installed-app data stays in the OS app-data directory under `Vapora`.

Windows checkpoint saving now retries brief file-replacement blocks. If saving still fails, the message names the filesystem error and a recovery action; the last successfully saved checkpoint stays intact. Fix the reported storage issue, then use Resume run.

The installer, Linux AppImage and macOS ARM64 DMG remain available. Enter a Steam Web API key using the toolbar key button for each app session. Downloads are unsigned by a publisher certificate and are not notarized. Check `SHA256SUMS.txt` against your download.

## verification

Native desktop CI tests the installed Windows app, the actual portable EXE, the extracted Linux AppImage and the mounted macOS DMG. Each check completes a fixture scan, downloads its exports and closes the native app. The portable check also moves the EXE and its data to another folder, reopens the saved run and downloads its exports without repeating Steam collection.

Core checks run on all three operating systems, including a 500-account fixture scan with concurrent saved-run reads. Windows checks reproduce real sharing locks and verify successful retry, permanent-failure reporting and checkpoint preservation. Browser E2E runs on Linux. These are local fixture checks; large live Steam networks remain untested.
