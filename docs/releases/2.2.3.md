# vapora 2.2.3

Ranking settings have shorter labels, aligned fields and help for every option. Contextual help works with keyboard focus, hover and click, avoids nearby controls and scrolls in short windows.

- Report and history tabs stay on one scrollable row, with buttons to reach hidden tabs.
- Settings and history import errors appear inside their dialogs. Failed settings saves keep a clear retry message.
- History comments use retained names and avatars. Dates, ban values and durations are easier to read; original records and exports keep their exact values.

The classic Steam olive theme, scan formulas, background history, independent Details windows and Obsidian vault export remain available.

Windows downloads include an installer and a portable EXE. The portable app keeps data in `Vapora-data` beside the EXE and needs about 1 GB free in Windows TEMP, plus space for scan data. Move the EXE and data folder together. Downloads are unsigned and not notarized; verify them against `SHA256SUMS.txt`.

Native package tests use local provider fixtures. This UI release does not change live Steam or history fetching behavior.
