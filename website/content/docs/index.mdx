Vapora is a local desktop, browser and CLI app for mapping public Steam friend networks. It collects public observations, computes network metrics, displays dated history and writes reusable reports.

## Version and scope

These pages describe the TypeScript + Effect application at version 2.2.0. Desktop packages contain the history runtime. Browser and CLI launches run locally from a source checkout. The original Python app lives on the [legacy branch](https://github.com/Microck/vapora/tree/legacy).

<Callout type="warn" title="Evidence has limits">Scores are heuristics. Public friendships, comments and self-reported location fields do not prove real-life relationships or residence. Private and unavailable observations stay unknown.</Callout>

Screenshots throughout this site use local fixture profiles.
